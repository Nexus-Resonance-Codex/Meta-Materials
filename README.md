## 🛠 Installation & Quickstart

### Environment Setup
We recommend using a virtual environment (e.g., `venv` or `conda`):
```bash
python3 -m venv nrc_env
source nrc_env/bin/activate
```

### Install Dependencies
```bash
pip install -r requirements.txt
pip install -e .
```

### Running Simulations
The core models are located in the `src/` directory. Run an electromagnetic performance audit natively:
```bash
python src/nri_simulator.py
```
